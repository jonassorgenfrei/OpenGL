# Gaussian splat sample data

`fox_statue.ply` is the original, unmodified 279,199-Gaussian `kitune1.ply`
Scaniverse capture. It contains logarithmic 3D scales, quaternion rotations,
opacity logits, and degree-3 spherical harmonics. The sample evaluates the SH
colors in the vertex shader for the current view direction. Press `P` to view
the same data as points. See `SOURCE.md` and `LICENSE.txt` for provenance.
